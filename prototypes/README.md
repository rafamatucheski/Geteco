# prototypes/

Trabalho isolado de arte e de conceito, **fora do mundo compartilhado**. Nada aqui é
carregado pelo jogo automaticamente: são cenas de demonstração e modelos que só entram no
jogo depois de uma integração explícita.

| pasta | conteúdo |
|---|---|
| `gameplay_repair_art_0909/` | **Território do Antigravity — não editar.** Demonstrações de caixão/funeral, Elias e a pá, e a prévia de retirada policial do motorista |
| `living_cast/` | Modelos de personagens e veículos, incluindo o `HarborPaintBay` usado pelo interior da garagem |
| `harbor_art_pack/` | Props do porto |
| `dante_cgi/`, `menu_concept/` | Conceito visual do protagonista e do menu |
| `garage/`, `loadout/` | Protótipos de interface |

## Regra de integração

Uma prévia funcionando aqui **não** significa que o sistema está pronto no jogo. A
integração precisa usar os pontos de encaixe reais (portas, poses, marcadores) do mundo
compartilhado, e é feita por quem cuida do gameplay — não dentro desta pasta.

Ao reportar progresso, distinga o que a demonstração mostra do que o jogo faz.
