## Começo, meio e fim

Inspecionados BuildingLife/Kit, CityPropKit e os arquétipos Urban*Building, junto aos
consumidores de batching, TunnelCutaway e ExteriorReveal. Os kits produzem recursos
ArrayMesh; a instância do lote nasce no montador bloqueado CityChunkDressing. BuildingLife
conecta uma única callback ao sinal child_entered_tree do chunk antes de esses lotes
nascerem. Sem modificar o montador nem acrescentar varredura por quadro.

Aplicado alcance e sombra desligada aos lotes classificados como pequenos adereços:
hidrante, lixeira, jornaleiro, caixa de correio, sacos, balizador, banco, jardineira,
respiro, parabólica, tubulação, ar-condicionado de janela, floreira, pombo, varal,
cartazes, conjunto de parabólicas e cadeiras de telhado. Nos prédios: lista positiva
para molduras/peitoris/vergas de janela, mullions, grelhas, cowling de ventoinhas,
flue pots e dentils. Limites de tamanho/volume evitam confundir lajes baixas com detalhes.

Preservados sólidos, coberturas, volumes principais, portas e maçanetas, vidro,
letreiros/emissivos, semáforos, postes, escadas de incêndio utilizáveis e mobília da
oficina. Nenhum nó foi renomeado/removido, material trocado, colisão modificada ou
hierarquia reparentada pela P5; referências e AABBs de cutaway/reveal continuam existentes.

Alcance: `40 + 4 + metade da diagonal do AABB transformado`, margem de 4 m. O renderer
mede do centro do AABB; a compensação impede que uma ponta/instância próxima suma
antes de 40 m. Lotes amplos conservam detalhes além de 40 m em vez de esconder peças
próximas. Não houve divisão dos MultiMeshes, que exigiria modificar o montador bloqueado.

Mobile/Compatibility usam histerese; Forward+ usa fade SELF. Fade de alcance não é
suportado no Mobile, conforme a [documentação oficial de GeometryInstance3D](https://docs.godotengine.org/en/stable/classes/class_geometryinstance3d.html#class-geometryinstance3d-property-visibility-range-fade-mode).
O renderer do projeto não foi alterado.

## Limitações e riscos para F/testador

- Não foi feita revisão renderizada temporal de pop-in, de dia/noite/chuva, nem benchmark;
  performance e qualidade visual permanecem não aprovadas nesta tarefa.
- O alcance de um lote inteiro é conservador; não significa descarte individual a 40 m.
- Chunks que não chamam BuildingLife.decorate não conectam o tratamento do mobiliário.
  A cobertura comprovada restringe-se aos trechos contados, não à cidade inteira.
- `HarborBuildingBatch._eligible` exclui malhas com alcance. Alguns detalhes passam a
  ficar separados, aumentando malhas; a redução de sombras não comprova ganho de CPU.
  F deve comparar P5 ligada/desligada no mesmo build e avaliar essa troca.
- Conferir corte/reaparição dos adornos, leitura de fachada/janela sem moldura distante
  e ancoragem visual do mobiliário sem sombra; conferir aproximação e afastamento
  atravessando o limite e passagem pelo túnel. Sem apagar luzes ou mudar qualidade global.


## Instrumentação reproduzível

Abaixo, o script de contagem usado (pode ser extraído para TEMP e executado com
Godot --headless --path D:/geteco/game --script caminho_do_script -- --no-save,
com GETECO_BAKED_BUILDINGS=0). Não acrescenta arquivos a outros donos.

```gdscript
extends SceneTree
const REGION = preload("res://world/regions/NativeRegion.gd")
const KIT = preload("res://world/city_look/CityPropKit.gd")
var failures := []
func _initialize(): run.call_deferred()
func run():
	await run_variant(false)
	await run_variant(true)
	print("P5_COMPARATIVO falhas=",failures)
	quit(0 if failures.is_empty() else 1)
func run_variant(enabled: bool):
	KIT.detail_range_enabled = enabled
	var region = REGION.build_region("harbor", Vector3.INF)
	region.initial_prewarm_only = true
	root.add_child(region)
	while not region.prepared: await process_frame
	for section in {"oeste": [Vector2i(1,1),Vector2i(2,1)], "leste": [Vector2i(5,1),Vector2i(6,1)]}:
		var counts := {"geometry":0,"meshes":0,"ranges":0,"shadows":0,"detail_instances":0,"protected_ranges":0}
		for key in {"oeste": [Vector2i(1,1),Vector2i(2,1)], "leste": [Vector2i(5,1),Vector2i(6,1)]}[section]:
			region._build_chunk(key)
			var chunk = region.chunks[key]
			await process_frame
			await process_frame
			for n in chunk.find_children("*","GeometryInstance3D",true,false):
				counts.geometry += 1
				if n is MeshInstance3D: counts.meshes += 1
				if n.cast_shadow != GeometryInstance3D.SHADOW_CASTING_SETTING_OFF: counts.shadows += 1
				if n.visibility_range_end > 0:
					counts.ranges += 1
					var world_bounds: AABB = n.global_transform * n.get_aabb()
					if n.visibility_range_end - n.visibility_range_end_margin - world_bounds.size.length()*0.5 < 39.99: failures.append("alcance menor que 40: " + str(n.name))
					if n.cast_shadow != GeometryInstance3D.SHADOW_CASTING_SETTING_OFF: failures.append("detalhe com sombra: " + str(n.name))
					counts.detail_instances += n.multimesh.instance_count if n is MultiMeshInstance3D else 1
					for protected in ["door","sign","neon","glass","roofsurface","fe_stair","fe_platform","beacon","workbench"]:
						if str(n.name).to_lower().contains(protected): counts.protected_ranges += 1
			region.chunks.erase(key)
			region._detach_cached_records(chunk)
			chunk.free()
		print("P5_CONTAGEM ligado=",KIT.detail_range_enabled," trecho=",section," dados=",JSON.stringify(counts))
		if counts.protected_ranges != 0: failures.append("alcance em peça protegida")
		if KIT.detail_range_enabled and counts.ranges == 0: failures.append("sem alcance no trecho " + section)
		if not KIT.detail_range_enabled and counts.ranges != 0: failures.append("interruptor não restaurou alcance")
	region.free()
	print("P5_CONTRATOS falhas=",failures)


```
